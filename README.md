# Memory Game

Игра на поиск пар. Игрок открывает карточки и запоминает их расположение, чтобы
найти все совпадения за наименьшее число ходов.

## Возможности

- Игра на 16 карточках: 8 пар, все рубашкой вверх при загрузке
- Счётчики ходов и найденных пар
- Несовпавшая пара остаётся открытой на 1 секунду, потом закрывается
- Кнопка «Новая игра» перемешивает поле и обнуляет счётчики без перезагрузки
  страницы
- Модальное окно победы с числом ходов
- Таблица лидеров: топ-10 результатов, сохранение в `localStorage`
- Перезапуск отменяет таймер закрытия несовпавшей пары

## Локальный запуск

Проект использует ES-модули, поэтому открыть `index.html` напрямую из файловой
системы не получится — браузер заблокирует загрузку модулей. Нужен локальный
веб-сервер.

Вариант 1 — Live Server в VS Code:

1. Открыть папку проекта в VS Code
2. Установить расширение Live Server
3. Открыть `index.html`, нажать «Go Live»

Вариант 2 — через терминал, если установлен Node.js:

```bash
npx serve .
```

После запуска приложение доступно по адресу, который выведет сервер, обычно
`http://localhost:3000`.

## Архитектура

Приложение разделено на три слоя по MVC:

- **Model** (`state.js`, `utils/storage.js`) — данные партии и сохранённые
  результаты. Не знает про DOM
- **View** (`view.js`, `modal.js`) — создание и обновление интерфейса. Не знает
  правил игры
- **Controller** (`controller.js`) — правила: открытие карточек, подсчёт ходов,
  блокировка во время закрытия пары, завершение игры

Вся разметка создаётся через `document.createElement` с помощью обёрток из
`utils/DOM.js`, поэтому в исходном `<body>` файла `index.html` присутствует
только `<script>`.
